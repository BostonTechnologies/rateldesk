## Dependency validation decision

JsonSchema.Net **7.4.0** from #247 is retained. The proposed 9.4.1 upgrade in
#239 is excluded after its API adaptation exposed 16 reproducible failures in
`TicketPaginationTests`: the evaluator rejects mathematically integral JSON
numbers such as `10e-1` and `100e-2`. These cases exercise `page` and `pageSize`
across incidents, requests, changes and request tasks. Existing expected results
and published schema semantics remain unchanged.

The diagnostic run passed 292 selected tests. Its 21 failures comprise the 16
schema regressions and five PostgreSQL cases blocked by unavailable local
Docker; the five provider cases are not evidence against the package's schema
behavior. Hosted validation of the final beta.10 combination remains required.
