# 0.1.2 stable candidate acceptance — 2 November 2026

## Tested implementation

The completed laptop campaign tested published `v0.1.2-beta.20`, source
`cec27571c73f0956207ca152fad58ef1f8c1be7a`. The stable preparation changes version
metadata and release documentation; runtime, migration, deployment and release
workflow implementation remain the same as that tested source. Required
exact-source CI and stable distribution verification remain separate gates.

The retained campaign covers the complete 390-operation inventory, with mode
and transport exclusions kept separate from positive results; 353 semantic
requirements; 103 domain cases; and 86 historical obligations comprising 250
slots. SQLite and PostgreSQL/Hybrid fixture tracks, six UI acceptance groups and
the mandatory transport controls are retained. This does not claim every
authentication mode has identical applicable operations.

All eight original findings and four later findings passed verification on the
final candidate. Functional completion was recorded on 1 November 2026. The
subsequent measured soak ran for 900.125 seconds, made 46 bounded requests and
recorded zero unexpected failures, with p95 latency of 125 ms against the
prospectively declared 5,000 ms budget.

## Cleanup and owner disposition

Every one of the 12,629 fixture occurrences in 43 original registries has an
explicit evidence disposition. Supported retirements, retained history,
independent native comparisons and historical issuer decommission remain
documented. A retired issuer is not described as an individual credential row
being marked revoked; source-only records are not asserted globally absent.

The remaining external-provider cleanup limitation concerned two disposable
Ethereal test-mail accounts whose credential revocation could not be proved
through the available supported controls. Their owned test folder was removed,
the web session was logged out, and the registered product mailboxes were
disabled with stored provider secrets absent. On 2 November 2026 the owner
explicitly accepted this limitation as non-blocking and authorized proceeding
to stable release preparation/publication.

The release disposition is **testing accepted with an owner-approved external
test-provider cleanup exception**. The original strict campaign receipt remains
`NOT_READY`; it has not been rewritten into a machine-validator pass, and no
provider account deletion or credential revocation is invented. The completed
product expiry, revocation, authorization and isolation tests retain their actual
outcomes independently of this test-service retention exception.

Private reports, original receipts, failed attempts, fixture registries and raw
evidence remain in owner-controlled custody. The curated evidence archive has
28,220 members verified by SHA256 and CRC readback. Its byte/member scans used
the current protected known-value union; all 3,074 retained distinct image OCR

repository contains no credentials, private profiles or campaign payloads.

Release readiness additionally requires a reviewed stable preparation merge,
