## Causal defect and repair

`AiAssistantChatSessionManager.SweepStaleProcessingAsync` treated elapsed
observation silence as loss of delivery, set `DeliveryUnknown` and retired a
healthy owner after five minutes. Its output consumer correctly fenced all
non-join output after that uncertainty boundary. Together these behaviors lost
the supported late answer from a still-running connected daemon.

The timer now records waiting while the original owner is connected, bound to
the same provider profile/session and still owns the active message. It does
not extend the timer or fabricate remote activity. Received output clears that
notice, saves the existing ordered events and can complete the original turn.
Row-lock validation rejects retired/replaced/profile-mismatched owners. Real
disconnection, buffer overflow, uncertain approval, restart and explicit Stop
waiting retain uncertainty and the late-output fence. No recovery sends a
message, tool action or approval response. Existing authorization is unchanged.

Waiting/resumed notices also advance the owner's durable sequence after commit.
The next live text delta therefore matches the API SSE cursor instead of being
discarded behind those newly saved notices. The two quiet-turn regressions
failed before this checkpoint correction and pass with the corrected sequence.

Automatic recovery is observational, cancellation-aware and finite: one attempt
per background sweep, six attempts per conversation/process with exponential
backoff capped at five minutes. Each connection/join attempt has a 30-second
deadline, including an unacknowledged connection. A healthy joined observation is retained even
when its history is inconclusive. Manual checking resets this retry budget;
neither the durable message nor the unresolved outcome is reset.

The shared composer previously let modifier handling diverge across consumers,
and its manual input/value render path could overwrite fast keystrokes. It now
uses Blazor's binding contract and sends the current DOM value. Enter admits
once; Alt+Enter replaces the selection with a newline. IME/repeated keydown,
busy/disabled/empty submission and frozen uncertain first-send identity stay
guarded. Shift+Enter and Ctrl/Meta+Enter remain aliases.
Fullscreen setup also stops its deferred focus callback from stealing the caret
from an already-focused composer or nested dialog. A controlled animation-frame
browser regression failed against the original callback before this repair.

## Actual supported protocol and remaining dependency

Current upstream `SessionOutputDto`/mapper and `SignalRSessionActor` were read
from the untouched upstream checkout. Live `turn_completed` carries a turn
number and outcome. `session_joined` carries recent role/content messages and
turn count, without an authoritative historical outcome bound to RatelDesk's
original client message ID or a durable approval replay guarantee. This repairs
quiet uninterrupted observation; it cannot prove the outcome of a missed turn
from the current historical contract. Ready, admission markers, tool results
and arbitrary assistant history are not terminal proof.

Managed environment access and running containers were inspected. Repository
and registry credentials are available for source/release work; no authorized
deployed NetClaw endpoint, device credential or live OAuth model binding is
configured for this environment. Available PostgreSQL and loopback browser
fixtures verify their stated layers. They do not establish deployed daemon or
provider behavior. A real 45-minute native run retaining its final result,
temporary native connection loss, API restart/missed-terminal recovery and
native pending/uncertain approvals remain open acceptance gates. #351/#308
must not be closed based on this beta's fixture/browser results.

[NetClaw #2791](https://github.com/netclaw-dev/netclaw/issues/2791) is separate.
Provider-stream fixes and their causal limits belong to that work. RatelDesk
does not claim to fix the production approximately 643-second provider cause.
NetRatel #646 authorization is unchanged.
