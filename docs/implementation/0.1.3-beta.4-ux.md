# 0.1.3-beta.4 UX implementation and delivery evidence

This record tracks [delivery #345](https://github.com/BostonTechnologies/RatelDesk/issues/345).
Source implementation, deterministic rendered acceptance, hosted CI and public
distribution are separate gates. Pending entries below do not claim acceptance.

## Baseline and compatibility

Work began on 5 November 2026 from freshly fetched main
`c1a3104d5d11f60a4a9676c6a10ea7dac903637f`, on
`feat/ux-beta4-workspaces`. There were no later main commits or overlapping open
feature PRs at discovery. This includes the #318 distribution work and #344 Web
IANA timezone and packaging repair. Existing package/runtime choices, native
archive entrypoints, notices, SQLite/PostgreSQL migrations and three image
families remain part of the regression contract.

The pinned SDK is 10.0.400. Applicable repository API/design, EF Core/database,
Playwright/Blazor and Slopwatch references govern the implementation. Shared
contracts remain DTOs/enums without UI, persistence or business-service dependencies.

Graph/native-daemon acceptance against real external services is distinct from
deterministic Graph and chat fixtures. The historical recovery issue
[#308](https://github.com/BostonTechnologies/RatelDesk/issues/308) remains outside
this campaign.

The combined rendered component run passed all 46 creation, state-popup and
data-wizard cases with zero skipped cases. Three additional OpenAPI cases passed,
including strict Release/Debug inventories and the identities, tags and documented
authentication of all nine new operations. The provider suite exercised real
SQLite/PostgreSQL, both new migration chains, cross-scope authorization,
idempotency, replica-safe Graph test receipts, interrupted-import recovery,
malformed-page preservation and typed scalar search under a non-English
culture. Read-only Graph tests leave configuration, rows, timestamps, keys and
schedules unchanged. Authenticated command clients do not replay mutations
automatically after transient errors or uncertain responses.

Final interaction corrections include scope-stamped stable lookup objects,
serialized multi-approver clearing, recoverable timeout/circuit failures, a
selective Enter/Space interceptor that prevents a duplicate native click, and
post-state selection reconciliation from the actual server response. This avoids
relying on MudBlazor's cached render rows or its short click-suppression interval.
Popup width and vertical scrolling have explicit viewport bounds.

The isolated coverage run passed 133 cases (120 backend/client/provider cases
plus the 13 existing wizard cases), with zero skipped cases and unchanged hashes
of the shared build files. This selected scope measured 87.4% line and 74.4%
branch coverage. Definition validation reached 100% sequence coverage and
94.8% branches; Graph workflow coverage was 90.9%/72.5%. Typed schema edits now
have direct SQLite/PostgreSQL coverage preserving dataset identity, raw rows and
named ingestion credentials, with invalid updates leaving saved state intact.
The analysis records remaining complexity in import orchestration and legacy
update/client methods; these selected-suite measurements are not whole-repository
coverage or acceptance against external Graph credentials.

The current MCP catalog was regenerated through its existing export test and
passed all 19 executable schema cases. Revision
`2026-11-05.beta4-contracts-v27` adds only optional dataset-creation
`request.body.requestId`; it retains 390 operations on 37 tools and every
confirmation/authority contract. The reviewed semantic delta is the revision,
two hashes and the two schema occurrences of that field. Historical catalogs
and inventory mappings retain their original bytes.

The final admin browser run passed 29 cases and four native Chromium 200% zoom
cases. It covered the real many-organization picker, dirty-context switches,
schema validation and uncertain creation, optional/one-time ingestion keys,
non-mutating Graph tests, persisted partial import results, unknown/zero counts
and deliberate recurring UTC schedule editing/cancellation. All focused
component/provider/browser results above have zero skipped cases.

clipboard payloads, denied clipboard fallback, reopen/history, fullscreen,

200%. The focused Release component run passed all 21 cases with zero skipped
cases (13 Markdown and eight shared Chat parity cases). Parser coverage was
