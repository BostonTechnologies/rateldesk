# 0.1.2-beta.10 candidate

Repairs the retained beta.9 campaign findings around notification readback,
strict MCP argument handling, archived mailbox cleanup and administrator mail.

## Repairs

- Exposes the persisted incident `LastViewedByCustomerAt` timestamp through
  authorized list, detail, create and update responses (#250).
- Counts every visible unread notification consistently in owner summary and
  unread-error reads, preserving recipient ownership for personal mark-read
  mutations (#251).
- Rejects duplicate outer MCP arguments on HTTP and stdio before business
  execution, including HTTP requests without a declared content length (#255
  and its beta.10 transport follow-up).
- Deletes an organization and its unused archived mailbox configuration in one
  transaction. Retained mail history, ingestion state and active processing
  produce an explicit conflict with no partial deletion (#256).
- Avoids a second workflow evaluation notification when an accepted approval is
  replayed after its continuation has settled. A replay that makes progress
  continues to publish the corresponding workflow events (#258).
- Rejects direct administrator mail with HTTP `409` and `queued: false` when no
  ready global sender exists, before creating outbox work (#260).

## Dependency updates

The candidate combines the refreshed .NET dependency group (#247, superseding
#238), Microsoft.Graph 6.8.0 (#149), API container base updates (#237), GitHub
Actions updates (#152), and Playwright 1.64.1 (#151). The complete combination
uses the normal repository and release validation gates.

JsonSchema.Net remains at **7.4.0**, supplied by #247. The proposed 9.4.1 update
(#239) is excluded: after adapting its changed API, focused validation reproduced
16 failures where its integer evaluator rejects valid pagination values written
as `10e-1` or `100e-2`. Beta.10 preserves the existing schema contract and tests.
