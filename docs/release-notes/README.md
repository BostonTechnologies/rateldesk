## 0.1.2-beta.3 candidate

The candidate separates **Verify existing deployment**, **Prepare configuration
changes** and **Connect a client**. Normal host adoption keeps the existing
four-service gateway and source bytes unchanged; deliberate corrections retain
readable operator sources and apply through their existing owner. Private pinned
Compose selection, compact host impact review and a stable status-verifier denial
retain explicit consent and exact target/permission boundaries.

Beta.2's client setup/profile reload, incident search, permission enforcement and
verifier cleanup remain required regression gates. Candidate/source notes do not
claim completed host acceptance, reviewed merge, hosted publication or verified
public downloads/images. [#198](https://github.com/BostonTechnologies/RatelDesk/issues/198)
and [#204](https://github.com/BostonTechnologies/RatelDesk/issues/204) remain open
until their actual delivery gates complete. See the
[operator guide](../mcp-http/setup.md) and [release engineering](../releases/README.md).
