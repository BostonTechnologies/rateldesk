# RatelDesk 0.1.4-beta.10

- Recover saved automation mappings that reference a unique Helpdesk field by name. Request submission and dispatch read the selected value from its stable field key. [#504](https://github.com/BostonTechnologies/RatelDesk/issues/504)
- Push from an existing Helpdesk field and save its mapping in the same review. Dataset multi-selects remain dataset fields and send one NetRatel Text input containing a JSON array. [#505](https://github.com/BostonTechnologies/RatelDesk/issues/505)
- Allow Helpdesk to push optional settings for ordinary job inputs. Inputs that select an execution target retain their requiredness guard. [#505](https://github.com/BostonTechnologies/RatelDesk/issues/505)

Pair with NetRatel 0.1.7-beta.4. For an affected form, open **Workflow → Review input differences**, choose **Push to NetRatel** for the input, confirm the existing Helpdesk source, and apply.
