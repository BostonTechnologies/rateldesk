Slopwatch 0.5.0 now runs in PR and release validation with a reviewed v2
baseline. Archives retain operator guides and are checked against the seven
published recovery ceilings. See [release engineering](../releases/README.md).

The stopped-wait path can retain a matching late result from the original live
connection. Disconnected recovery still depends on authoritative native replay.
The coordinated NetRatel version is 0.1.5. Verify the selected distributions and
complete paired functional testing before updating a production deployment.
