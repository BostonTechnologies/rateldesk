# 0.1.2-beta.14 candidate — campaign regression repairs

This candidate repairs eight defects reproduced in the beta.13 campaign:

- Incident message previews use the incident access policy and the current
  user's ticket scope.
- Long login headings wrap within narrow windows and enlarged text.
- Account Integration credentials remain visible when the optional organization
  chooser is unavailable to that account.
- Dataset-bound Text fields retain their supported schema type and binding when
  the request form builder saves them.
- Signed public ticket views and their public timeline work without a private
  session. Invalid signatures remain rejected and internal notes stay private.
- The existing 16,000 UTF16-unit chat limit can be sent as Unicode without
  exceeding the bounded Blazor receive frame limit.
- SharePoint synchronization uses Microsoft's documented site search query and
  retains paged ingestion for all configured Graph sources.
- PostgreSQL upgrades accept both known predecessor conversation-index names
  while preserving existing webhook and conversation data.

The regression tests cover scoped and foreign incident access, optional chooser
failures, field schema roundtrips, anonymous public views and reloads, invalid
signatures, narrow login headings, exact Unicode composer payloads, paged Graph
ingestion and both predecessor index variants. The complete provider suites and
existing release acceptance gates remain required.

Published beta.13 tags, assets and campaign evidence remain immutable. Passing
source tests establishes no deployed campaign result. After verified publication,
record the new candidate's exact source, archive hashes and image digests, then
run the full current catalog, all required domains and stateful histories, both
storage/authentication fixture tracks, the six UI groups and mandatory transport
matrix. Reconcile uncertain effects before retry, retain authentic provenance
for legacy history, prove all nine cleanup assertions and run the 15-minute soak
only after functional completion. Missing evidence remains explicit; it cannot

Follow [release engineering](../releases/README.md). The existing immutable
