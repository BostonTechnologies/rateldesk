# 0.1.3-beta.11 — owner-review workspaces and safe account cleanup

This candidate coordinates [#401](https://github.com/BostonTechnologies/RatelDesk/issues/401),
its table owners #402–#409, and the activation, organization cleanup and
cancellation reports #398–#400. Distribution receipts and the complete table
inventory are in the [campaign register](../implementation/401-owner-review-campaign.md).

Self Service reclaims the repeated root heading space. Tickets and Tasks expose
Tenant search in the normal toolbar; Tasks filters the complete authorized data
on the server. Ticket date/time pickers resolve browser timezone while retaining
saved UTC boundaries and DST validation. Tasks expand into a full-width child
pane. Roles and the remaining table owners share scoped compact chrome, calm
tabs and named icon actions. Operations diagnostics and role-assignment details
can page beyond their former first-page/capped results.
Email layout previews refresh when their rendered HTML changes, preserving the
authored content and its isolated presentation.

Local activation/reset validates required fields, email, matching confirmation
and the existing 15-character minimum, with safe actionable failures. Expected
request aborts are classified before fault notifications; real faults and
timeouts retain diagnostics. Organization deletion explains dependencies and
offers safe retention with a disabled organization, preserving revoked
credentials, archived history and uncertain-delivery safeguards.

The change adds no database migration or NetRatel protocol requirement. Keep
existing compatible pairings and lifecycle/recovery rules. Back up the database,
bootstrap state, protection keys and attachments before an operator-controlled
upgrade. Native AI chat retains its existing PostgreSQL requirement; supported
SQLite workflows remain supported. Production deployment is outside this campaign.
