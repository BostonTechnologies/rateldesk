# RatelDesk 0.1.4-beta.3

- **AI Providers** offers **Use an API project** for the managed OpenAI Agents API. Enter, replace or clear a project key in the WebUX and search the models returned by that project. Deployment references remain available. [#441](https://github.com/BostonTechnologies/RatelDesk/issues/441)
- **Use my ChatGPT plan** connects a private customer-operated Codex App Server through device sign-in. The profile binds to its original operator, tenant, account and model, and supports scoped read-only ticket MCP. [#441](https://github.com/BostonTechnologies/RatelDesk/issues/441)
- Hosted Agents profiles can save a validated versioned skill ZIP through **Advanced settings**. The selected archive stays pinned to the profile revision. [#441](https://github.com/BostonTechnologies/RatelDesk/issues/441)

The subscription path requires the pinned upstream runtime, a dedicated state volume and an eligible account with device sign-in enabled. It supports read-only MCP. Local workspaces, skills, subagents, artifacts and write approvals are unavailable on that path. Complete the synthetic acceptance procedure with the designated account and funding source before relying on live inference. [Setup and acceptance](../integrations/openai-agents.md)
