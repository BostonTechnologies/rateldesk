# RatelDesk 0.1.4-beta.8

- Request forms can accept multiple choices from predefined lists and authorized datasets. Search and page through dataset results while keeping selected options. Submitted information shows every recorded choice in Requests, My Requests and approvals. [#502](https://github.com/BostonTechnologies/RatelDesk/issues/502)
- NetRatel mappings can send those choices to an existing Text job parameter as a JSON array inside one string. [Script parameter examples](../integrations/netratel-orchestrator.md#map-multi-select-choices-to-a-job)

## Upgrade and retest

Pin the deployment to `0.1.4-beta.8` or the image digests in the release manifest.
Enable **Multi-select** on an existing predefined or dataset-bound field.
Submit synthetic choices from two searches, then check the saved labels in
My Requests. To verify a paired workflow, use the [no-op script examples](../integrations/netratel-orchestrator.md#map-multi-select-choices-to-a-job)
with a Text parameter and confirm the reported count.
