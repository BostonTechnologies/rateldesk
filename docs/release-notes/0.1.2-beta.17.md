# 0.1.2-beta.17

Setup now stops its terminal runner by cancelling a runner-owned token and
awaiting the render loop. This avoids a second terminal shutdown request racing
disposal of the library's internal cancellation source. Normal wizard exit,
host cancellation and concurrent exit follow the same lifecycle; failures from
the render task still propagate to the host.

The candidate retains the legacy automation-column migration and login-copy
wrapping changes described in [beta.16](0.1.2-beta.16.md). That tag was allocated
but its release validation failed during terminal teardown, before any release
assets or images were published. Its tag remains unchanged.

Publication follows reviewed PR/main checks and the existing immutable release
workflow. Fresh deployed campaign acceptance remains separate from source tests.
