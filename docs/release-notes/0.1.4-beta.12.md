# RatelDesk 0.1.4-beta.12

- Retry releases the hold owned by the failed attempt and retains the archived provider diagnostic. It can resume an unstarted retry left pending by beta.11 when the previous failure owns the hold. [#508](https://github.com/BostonTechnologies/rateldesk/issues/508)
- Execution readiness identifies missing, revoked and changed saved-account approvals and directs operators to **Paired Run as** in NetRatel. [NetRatel #859](https://github.com/BostonTechnologies/netratel/issues/859)

Upgrade NetRatel to 0.1.7-beta.6 first. Review the saved-account scope, refresh readiness, and retry the rejected task after correcting the configuration. The installed Windows on-behalf Add and Remove journey and published-artifact receipt timing remain pending owner acceptance.
