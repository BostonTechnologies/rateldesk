# 0.1.2-beta.13 candidate

Tracks [delivery #272](https://github.com/BostonTechnologies/RatelDesk/issues/272).
Publication and deployed acceptance remain separate from this source description.

- Administration → Integration consolidates system connections, API & MCP
  credentials and Netclaw, retaining existing entry routes and scoped account access.
- Administration → MCP Policies provides preview/confirm, versioned credential
  ceilings and immutable audit. Policies narrow RatelDesk HTTP MCP permissions;
  NetRatel execution authority remains managed by NetRatel.
- Operations → AI investigations and Prompts adds saved guidance revisions,
  authorized incident/request/change/task context, explicit Netclaw Send and
  global investigation search. Native chat retains its PostgreSQL requirement.
- Scoped IT support assignments propagate ticket permissions through the explicit
  organization support link, without propagating tenant-administration permissions.
- Local sign-in uses a compact label independent of branding length; PostgreSQL
  fixtures use the supported image-taking constructor.

The [laptop handoff](../mcp-http/beta13-laptop-campaign.md) preserves the supplied
beta.12 NOT_READY receipt and creates fresh candidate evidence. Existing fixes
for malformed MCP envelopes and mailbox disposal remain regression requirements.
The [query audit](../implementation/mcp-query-adapter-audit.md) records supported
identifier mappings and intentionally unsupported selectors.

Do not infer owner deployment, real-provider acceptance, completed soak, issue
closure or public artifact verification from these candidate notes.
