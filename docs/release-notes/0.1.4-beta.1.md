# RatelDesk 0.1.4-beta.1

- AI Providers in Administration → Integration configures Netclaw and OpenAI Agents API together. New conversations can use an eligible profile while existing conversations keep their original provider binding.
- OpenAI supports Chat and MCP and an optional hosted workspace with trusted skills and downloadable artifacts. The server keeps a durable transcript, checks pending actions and distinguishes cancellation, failure and uncertain delivery.
- Direct MCP uses a session-scoped ticket read policy. An optional internal incident note requires the original operator's explicit approval.
- PostgreSQL and SQLite migrations preserve existing chat rows and webhook configuration. Native chat continues to require PostgreSQL.

See the [OpenAI setup and live acceptance guide](../integrations/openai-agents.md), [Netclaw guide](../integrations/netclaw.md) and [release engineering](../releases/README.md).
