# 0.1.3-beta.1

This beta adds organization AI Chat and shared conversation presentation from
[#309](https://github.com/BostonTechnologies/rateldesk/pull/309), covering work
under [#305](https://github.com/BostonTechnologies/rateldesk/issues/305),
[#306](https://github.com/BostonTechnologies/rateldesk/issues/306),
[#307](https://github.com/BostonTechnologies/rateldesk/issues/307) and
[#308](https://github.com/BostonTechnologies/rateldesk/issues/308).

## Changes

- **Organization Chat:** open Operations → AI → Chat (`/ai/chat`) for general
  conversations without a ticket. Save multiple titled conversations, retain
  guidance snapshots, reopen stable links, search/page history and archive.
  Current organization permissions govern reads, sends and streams.
- **Shared fullscreen workspace:** maximize beside Archive in Chat,
  Investigations and ticket assistants. Restore the same conversation, composer
  draft and expanded calls; keyboard focus and Escape behavior are preserved.
- **Conversation preferences and traces:** share saved display preferences in
  the operator's browser, expand compact tool rows and inspect selected bounded
  JSON metadata. Sensitive values are redacted before storage and delivery.
  Safe Markdown, code blocks and copy controls retain readable output.
- **Conservative recovery:** persist check progress/results, avoid duplicate
  notices, refresh inconclusive results on a later manual check and allow
  acknowledged archival while retaining evidence. Recovery never automatically
  resends the uncertain message or retries an approval.

## Known recovery limitation and live acceptance

Issue #308 remains open. The inspected supported Netclaw join history does not
establish durable, exact-message terminal or approval replay. A turn admitted
before disconnection may still show an unknown outcome after recovery. This
beta cannot reliably restore a missed final report or distinguish historical
Completed, Running, Interrupted and AwaitingApproval outcomes from that history
alone. Admission, assistant text and unrelated terminal events are not treated
as proof of completion.

The owner will test against a live daemon after publication. Automated source,
provider and browser checks do not establish deployed native-daemon acceptance.
Plain/unstructured or malformed tool payloads are omitted for privacy; older
rows cannot display metadata that was never retained. See the
[Netclaw operator guide](../integrations/netclaw.md).

## Upgrade and test

Back up the database before upgrading. This version includes PostgreSQL and
SQLite migrations for explicit conversation scope and nullable ticket identity.
Native AI chat remains PostgreSQL-only; the rest of RatelDesk retains both
providers. A downgrade refuses to discard organization conversations, so retain
the backup if rollback is required.

1. In a disposable organization, create Chat with guidance, send once, reload
   its link, search/page history and archive. Switch organizations with an
   unsent draft and verify isolation.
2. Reopen an investigation and incident/request/change assistants. Check pinned
   context, current permissions and the exact approvals offered by the daemon.
3. Maximize and restore while streaming with a draft and expanded tool call.
   Check both themes, narrow screens, keyboard focus/Escape, copy and saved
   preferences.
4. Disconnect during an admitted native turn, then recover without resending.
   Check honest unknown results, repeated-check deduplication and acknowledged
   archival. Historical completion acceptance requires exact-turn replay
   evidence from the supported daemon contract.

## Distribution

Use the exact `0.1.3-beta.1` tag or a digest from the release manifest for
`ghcr.io/bostontechnologies/rateldesk-api`, `rateldesk-web` and
`rateldesk-mcp-http`. Each image supports amd64 and arm64. The GitHub prerelease
includes CLI/stdio archives for Linux x64/arm64 and Windows x64, deployment
documentation, `SHA256SUMS` and the release manifest. Verify checksums before
use. The stable `latest` channel remains on its separately approved release.
