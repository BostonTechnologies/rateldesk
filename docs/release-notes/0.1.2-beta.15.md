# 0.1.2-beta.15

The PostgreSQL upgrade removes the retained `IX_NetclawChatConversations_OrganizationId_TicketType_TicketId`
index. That superseded constraint could survive the beta.14 upgrade and reject an
investigation anchored to a ticket with an active conversation. The replacement
filtered index continues to enforce one active normal conversation while allowing
investigations. A separate follow-up migration covers databases that have already
completed the beta.14 migration chain; existing conversation and session data is
preserved.

The current campaign adapter now reads the repository's released catalog revision
alongside its product version. This permits the v26 catalog while preserving every
operation, domain, historical, transport, cleanup and post-functional soak requirement.
Three checksummed historical fixture files explicitly retain LF line endings on
Windows. Historical validators and their fixed checksums remain unchanged.

Publication follows the existing reviewed PR/main checks and immutable hosted release
workflow. Source regressions and publication checks do not replace fresh acceptance
against the published candidate.
