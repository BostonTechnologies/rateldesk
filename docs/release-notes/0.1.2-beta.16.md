# 0.1.2-beta.16

Older PostgreSQL stores can retain four `Sto`-prefixed automation binding columns
while migration history already records their original migration as applied.
Current queries expect `Orchestration` names, causing request submission to fail.
A forward migration renames the original columns without replacing binding rows,
values, indexes or migration history. Current schemas remain unchanged. Ambiguous
duplicate old/current columns stop the migration with an explicit diagnostic.

The login explanation now wraps an unbroken application name within the panel,
including narrow viewports and enlarged browser text. This extends the existing
heading wrapping fix to the explanatory copy.

Publication follows the existing reviewed PR/main checks and immutable hosted
release workflow. Fresh deployed upgrade, customer submission and visual
acceptance remain separate from source test results.
