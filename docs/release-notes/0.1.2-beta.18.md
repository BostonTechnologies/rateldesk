# 0.1.2-beta.18 candidate

This candidate includes repairs found during deployed campaign acceptance and
candidate regression testing:

- Login logos preserve their aspect ratio within the available branding space.
- Binding schema comparison treats `text` and `string` as the same field type,
  avoiding false drift between form fields and provider definitions.
- Scoped AI investigation setup loads the caller's authorized organizations
  through its scoped context lookup. Creating an investigation continues to
  require access to its selected ticket and organization.
- Incident Peek discovery describes the permission and organization checks
  already enforced by the API, including authorized scoped incident readers.
- Prompt editors apply edits to their read-only state and guidance that arrive
  during browser initialization, so clicking Edit while the editor loads does
  not leave the guidance locked or display an older value.

The existing 390 operations and their input schemas remain unchanged. The
current exported catalog includes the corrected Peek authority metadata.
Historical catalogs and published prerelease assets remain immutable.

Publication follows reviewed PR/main checks and the existing hosted release
workflow, preserving all three image families, both image architectures and
the CLI/stdio archives. Source tests and publication do not establish deployed
acceptance. The full fresh campaign, independent cleanup, post-functional soak
and strict evidence validation remain required under
[#219](https://github.com/BostonTechnologies/RatelDesk/issues/219).
